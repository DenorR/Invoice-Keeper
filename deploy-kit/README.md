# Invoice Keeper — установка на сервер

Один файл `invoice-keeper-1.2.1.run` ставит всё сам: приложение, Docker (если его нет), HTTPS и Telegram-бота.

**Нужно:** сервер Ubuntu 22.04+ или Debian 12, доступ root, свободные порты 80 и 443.

## Установка

**1. На своём компьютере** — скопировать файл на сервер. Двоеточие в конце обязательно:

```bash
scp invoice-keeper-1.2.1.run root@IP_СЕРВЕРА:
```

В Windows укажите полный путь к файлу: `scp C:\путь\invoice-keeper-1.2.1.run root@IP_СЕРВЕРА:`

**2. На сервере** — запустить установщик:

```bash
ssh root@IP_СЕРВЕРА
bash invoice-keeper-1.2.1.run
```

**3. Ответить на 5 вопросов** (выбор — стрелками ↑↓, подтверждение — Enter):

1. Логин и пароль администратора — ввести свой или сгенерировать.
2. Часовой пояс.
3. Адрес панели — HTTPS на `IP.sslip.io` (рекомендуется), свой домен или HTTP.
4. Telegram — вставить токен от [@BotFather](https://t.me/BotFather), затем написать любое сообщение в группе с ботом: чат найдётся сам.
5. Демо-данные и пароль демо-пользователей `user` и `accountant`.

Через 1–2 минуты появится таблица с адресом панели. Пароли на экран не выводятся. Сгенерированные лежат в `.env`:

```bash
grep -E '^(ADMIN_PASSWORD|DEMO_)' /opt/invoice-keeper/.env
```

## Управление

| Команда | Что делает |
|---|---|
| `invoice-keeper status` | состояние и проверка панели |
| `invoice-keeper logs` | журнал приложения |
| `invoice-keeper config` | изменить настройки (снова мастер) |
| `invoice-keeper restart` | перезапуск с применением изменений из `.env` |
| `invoice-keeper backup` / `restore ФАЙЛ` | резервная копия базы / восстановление |
| `invoice-keeper uninstall --purge` | удалить всё вместе с данными |
| `invoice-keeper help` | все команды |

## Администраторы

Задаются только в `/opt/invoice-keeper/.env`, через панель не меняются:

```text
ADMIN_LOGIN=admin
ADMIN_PASSWORD=основной-пароль
ADMINS=anna:Пароль-Анны-1,oleg:Пароль-Олега-2
```

`ADMINS` — дополнительные администраторы, пары `логин:пароль` через запятую (пароль от 8 символов, без запятой).
После правки выполните `invoice-keeper restart`. Обычных пользователей добавляют в панели, раздел «Пользователи».

## Обновление

Скопируйте на сервер новый `.run` и запустите его так же. Настройки и данные сохранятся, перед обновлением делается копия базы.

## Если что-то не так

- **`scp` не спросил пароль и написал «1 file(s) copied»** — пропущено двоеточие после адреса сервера.
- **Порт 80 или 443 занят** — остановите другой веб-сервер или выберите HTTP с другим портом: `invoice-keeper config`.
- **Панель не открылась сразу** — сертификат выдаётся до минуты, проверьте `invoice-keeper status`.
- **Мастер не нашёл чат** — этот бот запущен где-то ещё. Введите ID чата вручную: бот пришлёт его на команду `/chatid`.
- **Ошибка установки** — подробности в `/var/log/invoice-keeper-install.log`. Повторный запуск установщика безопасен.

Установка без вопросов: `ADMIN_PASSWORD=… TELEGRAM_BOT_TOKEN=… TELEGRAM_CHAT_ID=… bash invoice-keeper-1.2.1.run --yes`.
Все параметры: `bash invoice-keeper-1.2.1.run --help`.
