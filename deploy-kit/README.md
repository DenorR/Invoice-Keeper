# Установка Invoice Keeper на сервер

В этой папке всё, что нужно для развёртывания на Linux-сервере:

| Файл | Что это |
|---|---|
| `invoice-keeper-1.1.1.run` | установщик: приложение и мастер настройки в одном файле |
| `invoice-keeper-1.1.1.run.sha256` | контрольная сумма для проверки файла |
| `README.md` | эта инструкция |

Репозиторий, GitHub и сборка у себя не нужны: копируете один файл на сервер и запускаете.

## Что нужно на сервере

- Ubuntu 22.04+ или Debian 12, доступ под `root` (или через `sudo`).
- 1 ГБ памяти, 2 ГБ свободного места, выход в интернет.
- Для HTTPS свободны порты 80 и 443.
- Docker ставить заранее не нужно: если его нет, установщик предложит поставить его сам.

## Установка

Дальше `IP_СЕРВЕРА` — адрес вашего VPS, например `203.0.113.10`.

### Шаг 1. Скопировать установщик на сервер — на своём компьютере

Откройте терминал на своём компьютере и выполните `scp`. Укажите либо полный путь к файлу, либо сначала перейдите в эту папку `deploy-kit`.

**Windows** (PowerShell или «Терминал»):

```powershell
scp C:\путь\к\deploy-kit\invoice-keeper-1.1.1.run root@IP_СЕРВЕРА:
```

Например, если проект лежит в `D:\Hackathon`:

```powershell
scp D:\Hackathon\deploy-kit\invoice-keeper-1.1.1.run root@IP_СЕРВЕРА:
```

**macOS и Linux**:

```bash
scp ~/путь/к/deploy-kit/invoice-keeper-1.1.1.run root@IP_СЕРВЕРА:
```

- `scp` спросит пароль от сервера (или возьмёт SSH-ключ).
- Двоеточие в конце обязательно: файл ляжет в домашнюю папку `root` на сервере, то есть `/root`.
- `scp` уже есть в Windows 10/11, macOS и Linux. Если удобнее мышкой, скопируйте файл через WinSCP или FileZilla (протокол SFTP) в папку `/root`.

### Шаг 2. Запустить установщик — на сервере

Подключитесь к серверу и запустите файл:

```bash
ssh root@IP_СЕРВЕРА
bash invoice-keeper-1.1.1.run
```

Первая команда выполняется на вашем компьютере и открывает терминал сервера. Вторая выполняется уже на сервере.

Мастер работает прямо в терминале: на каждом шаге видно, что сейчас происходит,
выбор — стрелками ↑↓, подтверждение — Enter. Он задаст 5 вопросов:

| Шаг | Вопрос | По умолчанию |
|---|---|---|
| 1 | Логин и пароль администратора | `admin`, надёжный пароль генерируется |
| 2 | Часовой пояс для сроков и напоминаний | пояс сервера, иначе `Europe/Moscow` |
| 3 | Как открывать панель: HTTPS на `IP.sslip.io`, HTTPS на своём домене или без HTTPS | HTTPS на `IP.sslip.io` |
| 4 | Telegram: токен бота от @BotFather, затем мастер сам находит рабочий чат и присылает туда пробное сообщение | можно пропустить |
| 5 | Загрузить ли демо-данные (аренда в рублях, сервер в долларах, подписка в евро) | да |

Дальше установщик сам:
- поставит Docker, если его нет;
- запишет настройки в `/opt/invoice-keeper/.env`;
- соберёт и запустит приложение;
- получит HTTPS-сертификат;
- откроет нужные порты, если включён брандмауэр `ufw`;
- проверит, что панель отвечает.

В конце он покажет адрес панели и Swagger. Пароли на экран не выводятся — посмотреть их можно командой
`invoice-keeper credentials`.

**Как подключить Telegram на шаге 4:**
1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и вставьте токен в мастер.
2. Добавьте бота в рабочую группу и напишите там любое сообщение.
3. Мастер сам найдёт этот чат и пришлёт туда пробное сообщение.

## Команды после установки

Приложением управляет команда `invoice-keeper`:

| Команда | Что делает |
|---|---|
| `invoice-keeper status` | состояние контейнеров и проверка, что панель отвечает |
| `invoice-keeper info` | адрес, версия, часовой пояс, Telegram |
| `invoice-keeper credentials` | логины и пароли администратора и демо-пользователей |
| `invoice-keeper logs` | журнал приложения в реальном времени (`logs caddy` — веб-сервера) |
| `invoice-keeper start` / `stop` / `restart` | запуск, остановка, перезапуск |
| `invoice-keeper config` | снова пройти мастер: пароль, адрес, Telegram, часовой пояс |
| `invoice-keeper backup` | резервная копия базы в `/opt/invoice-keeper/backups` |
| `invoice-keeper restore ФАЙЛ` | восстановить базу из резервной копии (текущая сначала сохраняется) |
| `invoice-keeper reset-demo` | пересоздать базу с демо-данными (`--empty` — пустая база) |
| `invoice-keeper uninstall` | удалить контейнеры, данные и настройки сохраняются (`--purge` — удалить всё) |
| `invoice-keeper help` | справка |

## Обновление

Скопируйте на сервер новую версию установщика (как в шаге 1) и запустите её на сервере (как в шаге 2):

```bash
bash invoice-keeper-<новая версия>.run
```

Установщик увидит, что приложение уже стоит, и обновит его:
- сначала сделает резервную копию базы;
- заменит файлы приложения и пересоберёт его;
- настройки (`.env`) и данные останутся на месте.

Чтобы заодно поменять настройки, добавьте `--reconfigure`.

## Установка без вопросов

Для автоматизации все ответы можно передать переменными окружения и запустить с `--yes`. Всё, что не передано, берётся по умолчанию.

```bash
ADMIN_PASSWORD='Надёжный-пароль-1' \
TELEGRAM_BOT_TOKEN='1234567890:AAH…' TELEGRAM_CHAT_ID='-1001234567890' \
bash invoice-keeper-1.1.1.run --yes
```

| Переменная | Значение |
|---|---|
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | администратор; пароль генерируется, если не задан |
| `APP_TIMEZONE` | часовой пояс, например `Asia/Yekaterinburg` |
| `ACCESS_MODE` | `https` (адрес `IP.sslip.io`), `domain` или `http` |
| `DOMAIN` | свой домен для HTTPS, например `pay.example.ru` |
| `APP_PORT` | порт в режиме `http`, по умолчанию 80 |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | бот и чат для напоминаний |
| `SEED_DEMO_DATA` | `true` или `false` — загружать ли демо-данные |
| `INSTALL_DIR` | папка установки, по умолчанию `/opt/invoice-keeper` |

## Параметры установщика

```text
bash invoice-keeper-1.1.1.run [--yes] [--reconfigure] [--plain] [--extract ПАПКА] [--version] [--help]
```

| Параметр | Что делает |
|---|---|
| `--yes` | ставить без вопросов |
| `--reconfigure` | пройти мастер заново на уже установленном сервере |
| `--plain` | без анимации и стрелок: вопросы обычным текстом (для старых терминалов и записи в лог) |
| `--extract ПАПКА` | только распаковать и посмотреть, что внутри |

**Проверить, что файл не повреждён** (на своём компьютере, в папке `deploy-kit`):

macOS и Linux:

```bash
sha256sum -c invoice-keeper-1.1.1.run.sha256
```

Windows — сравните результат с числом из файла `.sha256`:

```powershell
Get-FileHash .\invoice-keeper-1.1.1.run -Algorithm SHA256
```

Установщик и сам проверяет контрольную сумму перед запуском на сервере, поэтому повреждённый файл не установится.

## Где что лежит на сервере

| Путь | Что там |
|---|---|
| `/opt/invoice-keeper` | приложение |
| `/opt/invoice-keeper/.env` | настройки и пароли, доступ только у root |
| `/opt/invoice-keeper/backups` | резервные копии базы |
| Docker-том `invoice-keeper_ik-data` | база данных, переживает обновления и перезапуски |
| `/usr/local/bin/invoice-keeper` | команда управления |
| `/var/log/invoice-keeper-install.log` | подробный журнал установки |

## Если что-то пошло не так

- **`scp` написал «1 file(s) copied», но пароль не спросил.** В команде пропущено двоеточие после адреса сервера (`root@IP_СЕРВЕРА:`). Без него файл копируется на ваш же компьютер под именем `root@IP_СЕРВЕРА`. Удалите эту копию и повторите команду с двоеточием.
- **Установщик остановился с ошибкой.** Подробности в `/var/log/invoice-keeper-install.log`. После исправления причины просто запустите установщик ещё раз: повторный запуск безопасен.
- **«Порт 80 (443) уже занят».** На сервере работает другой веб-сервер (nginx, apache). Остановите его или выберите режим без HTTPS с другим портом: `invoice-keeper config`.
- **Панель не открылась сразу после установки.** Сертификат Let's Encrypt выдаётся до минуты. Проверьте через минуту: `invoice-keeper status`.
- **Мастер не нашёл чат Telegram.** Так бывает, если этот же бот уже запущен на другом сервере: сообщения забирает он, а одного бота нельзя запускать в двух местах одновременно. Введите ID чата вручную (бот пришлёт его по команде `/chatid`) или создайте для этого сервера отдельного бота.
- **Напоминания не приходят.** Посмотрите `invoice-keeper logs`. Если с сервера Telegram доступен только по IPv6, установщик сам включает IPv6 для контейнеров (нужен Docker 27+).
- **Не Ubuntu или Debian.** Поставьте Docker Engine с Compose вручную ([инструкция](https://docs.docker.com/engine/install/)), затем запустите установщик.
