# Invoice Keeper — правила интерфейса

Короткий свод правил, по которым собрана панель. Новый экран делается по ним же. Тогда интерфейс
остаётся цельным и не выглядит «собранным из случайных блоков».

## 1. Принципы

1. **Главное видно за 5 секунд.** Наверху — только то, по чему принимают решение: просрочено,
   к оплате, оплачено. Всё остальное ниже или по клику.
2. **Цвет несёт смысл, а не украшает.**
   * Голубой aéza — главное действие, активный пункт меню, фокус.
   * Красный — просрочка. Жёлтый — скоро, срок сегодня или оплата с опозданием. Оранжевый не используется.
     Зелёный — оплачено. Серый — всё остальное.
   * Статус всегда показывается **точкой и текстом**: смысл не должен держаться на одном цвете.
3. **Иерархию задают вес и цвет текста, а не размер.** Основной текст 14 px. Подписи и метаданные —
   приглушённым цветом. Крупно и шрифтом Exo 2 — только заголовки страниц и ключевые числа.
4. **Плотность там, где ценность.** Списки плотные (строка 56–64 px), между смысловыми блоками — воздух.
5. **Одно действие на строку видно сразу.** Редкие действия (изменить, прекратить) спрятаны в меню «…».
6. **Тихие поверхности.** Тонкая рамка, почти незаметная тень, никаких тяжёлых цветных плашек.
   Предупреждение — короткая заметка строкой, а не алерт на всю ширину.

7. **Длинные списки не растягивают страницу.** На главной три отдельные колонки
   («Просрочено», «Ближайшие 7 дней», «Позже»), у каждой свой список высотой до ~400 px с прокруткой
   и мягким затуханием снизу, пока есть что прокрутить.
8. **Отметка оплаты — кружок в начале строки,** как галочка в списке задач. Оплаченный — зелёный
   с галочкой; нажатие на него открывает меню «исправить дату / чек / отменить».

## Матовое стекло

* **Стекло нейтральное.** Блоки не окрашены: белая вуаль в светлой теме (`rgba(255,255,255,.46)`) и едва заметная
  светлая на тёмной. `backdrop-filter: blur(36px)` без `saturate` — стекло только рассеивает фон, но не меняет
  его цвет. Цвет в интерфейсе остаётся только там, где несёт смысл: точки статусов, кружки-отметки, главная кнопка.
* **Фон — мягкие волны** голубого aéza и белого (залитые волнистые слои, `--ik-pattern` в `theme.ts`).
  Размытие запечено в SVG (`feGaussianBlur`), поэтому переходы плавные и не отвлекают от данных.
* **Карточки** — плотное матовое стекло как `bg-card`: скругление 22 px, тонкая рамка, тень `0 2px 10px rgba(0,0,0,.04)`.
  Карточка-показатель: справа точечная сетка с лёгким градиентом цвета карточки, крупное число (56 px, weight 500,
  трекинг −0.035em), сверху справа индикатор, снизу полоса с суммами по валютам.
* **Индикаторы** — иконка + текст нужного оттенка (`Pill`, `StatusBadge`), без плашек и точек с ореолом.
* **Размытие только на крупных поверхностях,** никогда на строках: `backdrop-filter` дорогой, особенно в Safari.
  Браузер без `backdrop-filter` получает плотную поверхность (`@supports not`).
* **Прокручивается область контента (`.ik-scroll`), а не окно.** Место под полосу прокрутки зарезервировано внутри
  неё (`scrollbar-gutter: stable`): страница не сдвигается вбок, когда список то длинный, то короткий, и при
  открытии окон. Сквозь это место виден фон — у прокрутки окна там оставалась бы пустая полоса.

## 2. Отступы (шкала 4/8)

| Где | Значение |
|---|---|
| Поля страницы | 32 px, на телефоне 16 px |
| Ширина контента | до 1200 px, по центру |
| Заголовок страницы → контент | 24 px |
| Между секциями | 32 px (`Section`) |
| Между карточками | 16 px |
| Внутри карточки | 20 px |
| Строка списка | 12–14 px по вертикали, 20 px по краям |

Блоки не «слипаются», потому что отступ задаёт контейнер (`Page`, `Section`, сетка карточек),
а не отдельный компонент.

## 3. Типографика и форма

* **Шрифты:** Exo 2 — заголовки и крупные числа, Inter — интерфейс. Числа и суммы — `tabular-nums`.
* **Скругления:** поля и кнопки 10 px, карточки 14 px, статусы — полностью круглые.
* **Тени:** в светлой теме едва заметная, в тёмной — нет, глубину даёт оттенок поверхности.
* **Суммы в тесных местах.** Столбцы таблиц фиксированной ширины (`table-layout: fixed`), чтобы длинная сумма не
  раздвигала соседей. В ячейке — компактное число `formatCompact` («977» + мелкое «млн»), точная сумма — в подсказке.
  Крупная сумма в карточке уменьшает шрифт по своей длине (`--len`), а не обрезается.
* **Строка списка:** у суммы и статуса свои столбцы; подпись под названием сокращается многоточием, на телефоне —
  переносится. Разделитель «·» рисует CSS (`[data-sep]`), в разметке только части подписи.

## 4. Движение (по Эмилю Ковальски)

Анимация нужна только там, где у неё есть смысл. То, что видят десятки раз в день, не анимируется
или почти не анимируется.

| Что | Как | Зачем |
|---|---|---|
| Нажатие кнопки | `scale(0.985)`, 240 ms | лёгкий отклик без «прыжка» |
| Меню, всплывающие окна | прозрачность + сдвиг 4 px + 0.98, 220–240 ms, из точки триггера | мягкое появление |
| Модальное окно | прозрачность + сдвиг 8 px + 0.98, 320 ms (закрытие 220 ms) | стандартное окно |
| Панель дня (drawer) | выезд 460 ms по кривой `cubic-bezier(.32,.72,0,1)`, закрытие 300 ms | закрытие быстрее открытия |
| Смена месяца в календаре | сдвиг на 10 px в сторону листания, 420 ms | движение объясняет направление |
| Карточки в панели дня | появление 420 ms с задержкой 45 ms на каждую | редкое действие — можно немного «живости» |
| Переход между страницами | только прозрачность, 280 ms | без резкой подмены содержимого, без движения |

* Кривые: `--ik-ease-out: cubic-bezier(0.22, 1, 0.36, 1)` (мягкий ease-out), `--ik-ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)`.
* Анимируются только `transform` и `opacity`.
* Эффекты наведения — только под `@media (hover: hover) and (pointer: fine)`, чтобы на телефонах не «залипали».
* Включено «Уменьшить движение» — остаются только изменения прозрачности.
* Модальное окно держим смонтированным и открываем через `opened` (см. `PayModal`): если монтировать его сразу открытым,
  Mantine не проигрывает появление и окно возникает рывком.

## 5. Компоненты

| Компонент | Где | Назначение |
|---|---|---|
| `Page`, `PageHeader`, `Section` | `components/common.tsx` | каркас страницы и единые отступы |
| `StatusBadge`, `Pill` | там же | статус: точка + текст |
| `DateTile` | там же | листок календаря в строке списка |
| `Notice` | там же | предупреждение строкой |
| `EmptyState` | там же | пустой список: иконка, пояснение, действие |
| `OccurrenceRow`, `OccurrenceList` | `components/OccurrenceList.tsx` | строки периодов, группы «Просрочено / 7 дней / позже» |
| `AezaLogo`, `AezaMark` | `components/Brand.tsx` | логотип из брендбука, сам меняет цвет под тему |

Токены цвета и поверхностей: `theme.ts` (палитры, `cssVariablesResolver`) и CSS-переменные
`--ik-border`, `--ik-surface`, `--ik-surface-2`, `--ik-hover`, `--ik-page-bg`.

## 6. Проверка перед сдачей экрана

- [ ] Видно, что главное на экране, без чтения всех подписей.
- [ ] Между блоками отступы из шкалы, ничего не прилипает.
- [ ] Обе темы: светлая и тёмная.
- [ ] Ширина 375 px (телефон): ничего не обрезано, кнопки нажимаются пальцем.
- [ ] Пустое состояние и загрузка (скелетон) выглядят аккуратно.
- [ ] Статусы различимы без цвета.
- [ ] Длинные суммы (миллиарды) не наезжают на соседей и не обрезаются посередине.
